# R. Hood brush logo — maker's mark

`public/assets/ui/brand/r-hood.svg` is a vector tracing of the project owner's
"R. Hood." brush wordmark (an arrow striking a bullseye forming the "o"),
supplied 2026-09-06. Owner-supplied artwork, recorded as
`LicenseRef-Project-Owner-Authorized`. Traced with potrace and recoloured to
`currentColor`. Used as a small maker's mark on the intro screen; the bullseye
motif also informs `favicon.svg`. The game title remains "Sherwood Rebellion".
